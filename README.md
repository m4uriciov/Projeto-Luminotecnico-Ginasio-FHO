# 💡 Projeto Luminotécnico do Ginásio Poliesportivo Coberto da FHO.
Este repositório apresenta o desenvolvimento completo de um projeto luminotécnico e elétrico para um ginásio poliesportivo coberto, realizado como Trabalho de Conclusão de Curso do curso de Engenharia Elétrica. O projeto contempla o dimensionamento da iluminação para a quadra, arquibancadas, áreas externas e de entrada, bem como o dimensionamento dos condutores e disjuntores dos circuitos envolvidos.
O ginásio foi modelado como uma estrutura multifuncional, adequada para práticas esportivas e eventos, seguindo os critérios técnicos das normas ABNT NBR 5410, NBR 8995-1, ABNT NBR 5101 e diretrizes específicas do setor de iluminação esportiva.
## 📌 Objetivos do Projeto
•  Elaborar um projeto luminotécnico completo e funcional para um ginásio coberto;

•  Garantir os níveis de iluminância, uniformidade e conforto visual exigidos pelas normas;

•  Simular e validar o sistema no Dialux Evo;		

•  Dimensionar condutores, disjuntores e circuitos elétricos conforme a NBR 5410;

•  Propor uma solução segura, eficiente e normatizada.
## 🔍 Conteúdo Técnico
O projeto contempla todas as etapas essenciais de um sistema luminotécnico e elétrico voltado para instalações esportivas:
### 💡 Projeto Luminotécnico
•  Simulação no Dialux Evo considerando as dimensões reais do ginásio;

•  Ambientes contemplados: Quadra poliesportiva (300 lux), Arquibancadas (150 lux),	Área de entrada (50 lux) e Área externa (30 lux);

•  Definição de índice de reflexão, fator de manutenção e uniformidade mínima;

•  Escolha criteriosa de luminárias LED com distribuição adequada para esportes;

•  Atendimento às exigências da norma NBR ISO/CIE 8995-1.
### 🔌 Dimensionamento Elétrico
•	Quadro de cargas por setor, com detalhamento das potências totais;

•	Cálculo da corrente nominal de cada circuito;

•	Dimensionamento de condutores conforme capacidade de condução, queda de tensão e seção mínima (NBR 5410);

•	Seleção de disjuntores termomagnéticos compatíveis com a proteção de cada circuito de iluminação;

•	Verificação da coordenação entre proteção e condutor.
## 🛠️ Ferramentas Utilizadas
•	Dialux Evo – Simulação e cálculo luminotécnico;

•	AutoCAD – Planta baixa e disposição dos elementos;

•	Qeletrotech - Elaboração diagrama Unifilar;

•	Normas ABNT – Referência técnica e normativa.
